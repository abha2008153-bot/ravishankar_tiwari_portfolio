## Replace the portrait
Put the real professional photograph at:

`assets/ravi-shankar-tiwari.jpg`

Then change this line in `index.html`:

`<img src="assets/ravi-shankar-tiwari-placeholder.svg" ...>`

to:

`<img src="assets/ravi-shankar-tiwari.jpg" alt="Portrait of Advocate Ravi Shankar Tiwari">`
